1 Transformer & Self-Attention 원리

단어 간의 관계를 한 번에 병렬로 계산하는 최신 언어 모델의 뼈대입니다.

Attention(Q, K, V) = softmax(QKᵀ / √d) V

• Q(Query): 내가 찾는 단어 / K(Key): 비교할 대상 단어 / V(Value): 단어의 실제 의미 벡터

2 RAG (검색 증강 생성) 아키텍처

모델의 거짓 답변(환각)을 줄이고 최신/내부 문서를 참고해 답변하도록 돕는 기술입니다.

  1. 문서를 여러 조각(Chunk)으로 쪼갭니다.
  2. 조각들을 벡터(숫자 배열)로 변환해 Vector DB에 저장합니다.
  3. 사용자가 질문하면 가장 관련 있는 조각을 찾아옵니다.
  4. 찾아온 내용과 함께 질문을 LLM에 넘겨 정확한 답변을 얻습니다.
3 LoRA 파인튜닝 (PEFT)

거대한 AI 모델의 전체 가중치를 다 고치지 않고, 아주 작은 추가 행렬(A, B)만 훈련시켜 적은 그래픽카드 메모리로 원하는 목적에 맞게 맞춤 학습시키는 기법입니다.
